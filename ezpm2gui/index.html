Features

Everything you need to master PM2

From real-time monitoring to one-click deployments — all the tools in one elegant interface.

Real-time Monitoring

Track PM2 processes with live CPU, memory, status, and system resource readings.

Process Control

Start, stop, restart, and delete processes with one click. Graceful reload supported in cluster mode.

Remote Servers

Manage PM2 processes on multiple remote servers via SSH — all from a single dashboard.

One-Click Deploy

Start applications from a form with entry points, runtime options, and environment variables.

Log Viewer

Stream, filter, and download stdout/stderr logs. Adjust line counts on the fly.

Cluster Mode

Choose an instance count, switch execution mode, and gracefully reload compatible clustered apps.

Cron Jobs

Schedule recurring tasks with cron expressions. Supports shell, Node.js, Python, and .NET.

Process Metrics

Live sparklines for every process — rolling 1-hour CPU and memory graphs updated every 3 seconds. Switch to History for recorded remote-server metrics stored in SQLite.

Access & Credentials

Optional password and PIN protection, with encrypted SSH credentials stored on the GUI server.

Update Controls

Check for and install new versions from inside the dashboard. No terminal needed.

Built with modern technologies
Node.js React TypeScript Express Chart.js Tailwind CSS
Interface

See it in action

Clean, developer-focused screens built to give you information at a glance.

Process Dashboard

All running PM2 processes with CPU, memory, and uptime at a glance.

Process Details

Deploy Application

Cron Jobs

Schedule recurring tasks with standard cron expressions — shell, Node.js, Python and .NET.

Remote Servers

Settings

Quick Start

Up and running in seconds

Multiple installation options to fit your workflow.

1

Install globally

$ npm install -g ezpm2gui
2

Launch the server

$ ezpm2gui
3

Open in your browser

Navigate to http://localhost:3101 — your PM2 processes load instantly.

1

Run directly with npx (no install needed)

$ npx ezpm2gui
2

Or install as a local project dependency

$ npm install ezpm2gui
3

Add a script to package.json

> "pm2-ui": "ezpm2gui"
1

Build from the repository

git clone https://github.com/thechandanbhagat/ezpm2gui.git cd ezpm2gui docker build -t ezpm2gui:local .
2

Run with persistent data

docker run --name ezpm2gui -p 127.0.0.1:3101:3101 \ -v ezpm2gui-pm2:/app/.pm2 \ -v ezpm2gui-config:/app/dist/server/config \ -v ezpm2gui-uploads:/app/uploads \ ezpm2gui:local

This manages PM2 inside the container. For PM2 on another machine, use Remote Servers. Application files and runtimes must be available in the container.

Docker setup details →

Compatible with Linux, macOS, and Windows. Use Node.js 24 (tested with this checkout) and PM2 installed globally (npm install -g pm2).
